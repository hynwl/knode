# 에러 코드 (AC-Exxx)

> 이 문서는 `backend/app/schemas/errors.py` 의 `ISSUE_CATALOG` 에서 `backend/scripts/gen_errors_doc.py` 로 **자동 생성**된다. 코드를 추가/수정하려면 `ISSUE_CATALOG` 와 `frontend/src/validation/issues.ts` 를 먼저 1:1로 맞춘 뒤 이 스크립트를 다시 실행할 것 — 직접 편집하지 말 것.

모든 검증/실행 에러는 `AC-E`(error) 또는 `AC-W`(warn) 접두 코드를 가진다. 앱 안의 에러 토스트/인스펙터 배지에 뜨는 코드를 여기서 그대로 검색하면 된다.

## E1xx — 그래프 구조

<a id="AC-E101"></a>
### `AC-E101` 🔴 error

**Crew 노드가 없습니다**

힌트: 우클릭 → Flow → Crew 를 추가하세요.

<a id="AC-E102"></a>
### `AC-E102` 🔴 error

**Crew 노드가 2개 이상입니다**

힌트: 하나만 남기세요.

<a id="AC-E103"></a>
### `AC-E103` 🔴 error

**hierarchical 프로세스에는 Manager LLM 이 필요합니다**

힌트: Crew 의 manager llm 소켓에 LLM 을 연결하세요.

<a id="AC-W104"></a>
### `AC-W104` 🟡 warn

**Crew 에 연결되지 않은 노드가 있습니다**

힌트: 실행에서 제외됩니다.

<a id="AC-E105"></a>
### `AC-E105` 🔴 error

**순환 의존이 감지되었습니다**

힌트: Task 의 depends on 연결을 확인하세요.

<a id="AC-E106"></a>
### `AC-E106` 🔴 error

**호환되지 않는 포트 연결입니다**

힌트: 같은 색 소켓끼리만 연결할 수 있습니다.

<a id="AC-E107"></a>
### `AC-E107` 🔴 error

**Crew 에 Task 가 없습니다**

힌트: 최소 1개의 Task 를 Crew 에 연결하세요.

## 전송 계층 (요청 / 서버)

그래프의 특정 노드가 아니라 **요청 자체**나 **서버**에서 난 오류다. `backend/app/core/errors.py` 의 `TRANSPORT_ERRORS` 가 소스다.

<a id="AC-E001"></a>
### `AC-E001` 🔴 error

**요청 본문이 올바르지 않습니다.**

힌트: 요청 스키마를 확인하세요.

<a id="AC-E500"></a>
### `AC-E500` 🔴 error

**서버 내부 오류가 발생했습니다.**

힌트: 잠시 후 다시 시도하세요. 문제가 계속되면 로그를 확인하세요.

### `AC-E<HTTP 상태코드>` 🔴 error

**HTTP 상태코드를 그대로 실은 동적 코드** — 없는 URL 은 `AC-E404`, 허용되지 않은 메서드는 `AC-E405` 처럼 나온다. 개별 항목이 아니라 HTTP 의미 그대로 읽으면 된다.

> ⚠️ **위 E4xx 항목과 코드 문자열이 겹칠 수 있다.** 같은 `AC-E404` 라도 `node_id`/`hint` 가 없으면 그래프 이슈가 아니라 이 전송 계층 에러다 (`backend/tests/test_main.py::test_404_uses_error_envelope` 가 이 구분을 고정한다).

힌트: 숫자 부분이 곧 HTTP 상태코드다. 요청 URL/메서드를 먼저 확인하세요.
